# 8 Week SQL Challenge

This repository contains my solutions to the [8 Week SQL Challenge](https://8weeksqlchallenge.com), which was created by [Data With Danny](https://www.datawithdanny.com). The case studies were very engaging and a great way to introduce myself to more advanced SQL skills, such as window functions and CTEs!
